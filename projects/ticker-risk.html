Single-Asset Risk by Ticker

The same four Value-at-Risk models and historical stress tests as the portfolio tools, run one asset at a time on ten stocks, ETFs and crude oil futures.

Choose a Ticker Portfolio Tools View the Code on GitHub

Each stock or ETF is a $1m position held at constant value. Each crude oil future is one contract of 1,000 barrels, so its P&L is the change in price times 1,000. That way the analysis still works on 20 April 2020, when WTI settled at −$37.63 and percentage returns stop making sense.

The models are historical simulation, normal, EWMA and GARCH filtered historical simulation. Each forecasts tomorrow from data up to today, over each asset's full history. The backtests are the same as in the portfolio tools: Kupiec, Christoffersen, the Basel traffic light and an Expected Shortfall check.

Data and Caveats

  • Prices are daily closes from Yahoo Finance via the yfinance library, adjusted for splits and dividends. Yahoo data is for personal use, so this page shows results only: no price or return series are published.
  • The crude oil series are Yahoo’s continuous front-month contracts. They are spliced without back-adjustment, so each roll day adds an artificial price jump to the P&L.
  • Positions are hypothetical and held at constant size, so the backtests judge the models rather than any trading.
  • Stress scenarios apply each window’s move to the position at once, and only windows inside the asset’s history are shown.

Any ticker can be run locally with scripts/analyze_ticker.py in the repository.
